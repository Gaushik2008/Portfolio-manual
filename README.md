# Gaushik Kumar G — Personal Portfolio

A responsive, single-page personal portfolio introducing my background, technical skills, selected projects, and contact information.

🌐 **Live website:** https://gaushik2008.github.io/Portfolio-manual/

## Overview

This portfolio is a simple web presence built with HTML and CSS. It brings together a short introduction, a skills list, featured project summaries, and ways to connect with me.

## Website Sections

- **About Me** — A brief introduction and my interests in software development, DevOps, and AI automation.
- **Skills** — A snapshot of technologies and tools I am learning and working with.
- **Projects** — Highlights of two projects:
  - **Financial Leakage Intelligent System** — An AI-powered concept for detecting and preventing financial leakage.
  - **UrbanPulse** — An AI-powered mobile urban intelligence system.
- **Contact** — Email, GitHub, and LinkedIn links.

## Built With

- **HTML5** — Page structure and semantic content.
- **CSS3** — Styling, Flexbox, CSS Grid, hover transitions, and responsive layout.
- **Font Awesome 6.7.2** — Icons, loaded through the CDN.

## Run Locally

No build tools or package installation are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/Gaushik2008/Portfolio-manual.git
   ```

2. Open the project folder:

   ```bash
   cd Portfolio-manual
   ```

3. Open `index.html` in your browser.

   You can also use the **Live Server** extension in Visual Studio Code for local preview.
